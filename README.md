# scope-fw
This is the firmware written in C with the C pico-sdk and [pico-displayDrivs](https://github.com/tvlad1234/pico-displayDrivs) library for our project [infiniscope](https://github.com/Ahad732/Infiniscope)

The firmware is to be built via cmake and then the uf2 is to be dragged and dropped into the RP2350 in boot mode.
